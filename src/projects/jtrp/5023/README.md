# SPR 5023: Understanding and Shaping Driver Behavior and Public Perception at Reduced Conflict Intersections (RCls)

This folder contains the code for JTRP project 5023. The objective of this project are as follows:

- Develop an evidence-based understanding of how drivers perceive, interpret, and navigate RCIs, using field observations, surveys, and driving simulator experiments.
- Identify design pain points and behavioral bottlenecks among key driver populations and use these insights to inform driver-centric improvements to signage, markings, and intersection geometry.
- Build a coordinated public outreach and education campaign in partnership with the Purdue Office of Engagement, using interactive tools and community-facing materials to improve understanding and acceptance of RCIs across Indiana.
